# Product Overview

This project is a **terminal-based 4x4 Tic-Tac-Toe game** for two players.

## Core Concept

- Played on a 4×4 grid (16 cells, numbered 1–16)
- Two players alternate turns: Player X and Player O
- Win condition: 4 consecutive symbols in a row, column, or diagonal
- Draw condition: all 16 cells filled with no winner
- Runs entirely in the terminal with ANSI color support

## Key Features

- Color-coded output: X in red, O in blue, prompts in yellow, win messages in green, errors in red
- Graceful fallback to plain text when ANSI colors are unsupported
- Input validation with clear error messages
- Play-again prompt after each game ends (both players must agree to replay)

## Language

Requirements and documentation are written in **Vietnamese**. Code, identifiers, and comments should be in **English**.
